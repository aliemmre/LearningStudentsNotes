# Learning Students Notes

A Java desktop application developed for managing and processing student information and source lists.

## Overview

Learning Students Notes is a Java-based desktop project that combines data structures, file processing, GUI components, and automated project checks.

The project was developed as a learning-oriented application and brings together several concepts from Java programming and data structures.

## Features

- Student information processing
- Source list management
- File-based data processing
- Custom data structures
- Hash table operations
- GUI-based interaction
- Automated project checks
- Text file handling
- Logging and result generation

## Technologies

- Java
- Java Swing
- NetBeans
- Java build tools
- Git & GitHub

## Data Structures

The project contains custom implementations and usage of data structures for processing student and source-list information.

The implementation includes structures such as:

- Linked Lists
- Hash Tables
- Separate Chaining
- Linear Probing
- Custom Node structures

## File Processing

The project uses Java file-processing APIs to read, write, search, and process text-based data.

Student information, source lists, and generated logs are handled through files inside the project.

## GUI

The project contains a graphical user interface implemented with Java Swing.

The GUI provides interaction with the application's student and source-list processing functionality.

## Testing

The project contains its own project checks under the `test` directory.

These checks are used to verify important parts of the application and help ensure that the existing implementation behaves as expected.
